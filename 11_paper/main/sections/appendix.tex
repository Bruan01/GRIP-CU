\subsection{WN18RR三来源对照与历史候选池核验范围}
\label{sec:wn-exploratory}

WN18RR共12,334条训练QA，其中2,709条关系问题具备候选损失资格，每题包含九个互异候选。历史Full在完整验证集上选定$\lambda_{\mathrm{cand}}=0.25$，训练5个epoch、125个优化步，候选损失温度为1.0。LoRA rank/alpha为24/48，学习率为$10^{-3}$，权重衰减为$10^{-4}$，微批大小为4，梯度累积为128，精度为bfloat16。新增Uniform与Full配额匹配随机保持这些设置及相同Stage~1初始化、QA和资格门，各训练125步，不重新验证选模；Full直接结果与权重复用历史获选模型。因此，这不是三种候选策略分别独立调参后的最优比较，也不是三个模型均以本次同版本代码重新训练。

完整3,134题测试保留原十一选项及其顺序；训练负例数$K=9$不改变评测选项数。三模型重排采用与FB相同的标签续接平均对数概率、$[-20,20]$裁剪及原顺序破平局规则。Full的直接EM/H@1/MRR/H@3为86.89/88.42/93.15/97.83\%，完整三个来源均列于正文表~\ref{tab:cross-dataset-sources}。同一测试文件上的本地B1直接EM为32.67\%，与原始GRIP报告的五次运行均值64.30\%存在尚未解释的复现差异\citep{feng2025grip}；新增来源控制没有修复B1，也不据此宣称相对修复基线的增益。

候选来自训练关系词表，但训练实体对核验并非全部完成：2,654条合格QA可与训练事实精确对应，另外55条历史评分记录的实体对为空，现有QA亦无法与训练实体对精确匹配。为保持与已训练Full一致，两个控制保留这些QA的原始文本与历史排除mask，单独标记核验缺口；不能将这55条计为训练已知关系独立核验通过。因此，WN结论限定为历史候选池条件下的单种子比较。

合法池中2,703题有10个负关系、6题有9个负关系，$K=9$接近穷举。Full与Uniform平均共享8.107个候选，与配额组共享8.644个；配额匹配在2,709题全部成功，无跨桶回退，24,381个槽位中22,391个因桶内池大小受限而被强制确定。较小候选自由度与较大结果差异同时存在，不能将WN表现单独归因于候选池规模或已证实的桶内身份机制；历史Full选模、代码版本与训练随机性等比较边界仍需保留。

\subsection{候选库记录与构造伪代码}

每条候选库记录包含问题标识、数据划分、实体对、目标关系、候选关系和采样来源。逐候选记录包括结构相似度、违例度、utility、B1 候选分数及其与目标分数的差值；来源清单包含过滤划分、采样参数、随机种子、脚本版本和文件哈希。这些字段将候选采样结果关联到原始任务及其离线评分。

{\small
\begin{verbatim}
for q in train_questions:
    assert q.split == "train"
    P = train_relations - {q.gold} - known_train_relations(q.head, q.tail)
    if len(P) < K:
        record_insufficient_pool(q)
        continue
    for r in P:
        s = profile_similarity(phi[q.gold], phi[r])
        v = b1_score_violation(q, r)
        u[r] = alpha * s + beta * v
    candidates = sample_without_replacement(
        P, mixture_softmax(u, rho, tau_s), K=9)
    write_frozen_bank(q, candidates, manifest=provenance)
\end{verbatim}
}

候选库按训练来源限定、已知关系过滤和候选采样的顺序构建。来源检查核对问题标识与关系文本的一致性，固定候选库供整个 Stage~2 使用。

\subsection{FB候选来源对照的复现设置}
\label{sec:fb-repro}

FB五组固定Stage~1、12,136条QA、3,109条候选资格和每题九候选。LoRA rank为24，alpha为48，目标模块为\texttt{down\_proj}、\texttt{up\_proj}和\texttt{gate\_proj}；微批大小为1，梯度累积为512，精度为bfloat16。获选学习率为$9.4762275\times10^{-4}$，权重衰减为$8.8899022\times10^{-5}$，Adam epsilon为$10^{-8}$；候选损失权重为0.11229874，候选温度为0.88639612。训练实际停止于32步，同时保留五轮、120步线性调度。候选采样参数与损失温度分别记录，不将采样温度0.25当作候选损失温度。

Full采用结构/违例权重1/1，Profile-only为1/0，Violation-only为0/1；三组均保留均匀下限$1/3$和采样温度0.25。均匀随机从完整合法池无放回抽样。Full由验证集选定；Random复用其配置并曾完整评估验证集，单信号和配额匹配组则预先固定32步，不执行新完整验证或重新选模。

对频率配额匹配组，记Full候选的桶序列为$(b_1,\ldots,b_9)$，其中$b_i=\lfloor\log_2 f(r_i)\rfloor$。对桶$b$，合法池为$P_{q,b}=\{r\in P_q:b(r)=b\}$，配额为$m_{q,b}=\sum_i\mathbf{1}[b_i=b]$。在$P_{q,b}$中均匀无放回抽取$m_{q,b}$个关系，依次放回原桶槽位；对同桶第$j$次抽取，其条件概率为$1/(|P_{q,b}|-j+1)$。配额不足时拒绝继续，不跨桶补齐。Full候选允许被重新抽到，避免通过排除原候选引入额外干预。所有统计仅来自训练图和已冻结Full训练候选，不使用验证/测试关系频次。

分层分析在完整测试结果已观察后进行。分组边界取训练词表关系频次排序的第$\lceil R/3\rceil$和第$\lceil2R/3\rceil$个值（$R$为训练关系数），分别为215和689；同频次保持同组。按测试中出现的关系等权平均其EM，得到表~\ref{tab:fb-macro}；未在测试中出现的训练关系不补零。各组的测试关系数分别为低频67、中频72、高频76，完整测试共215个关系。该统计与按测试题等权的总体EM具有不同权重。

\subsection{FB匹配重排与K敏感性的补充设置}
\label{sec:fb-rank-repro}

三来源重排复用正文固定模型，全部使用同10,000题和原十选项，不将重排输出重新计作直接解码。评分对包含答案标签的续接token取平均对数概率，沿用原评分实现中区间$[-20,20]$的裁剪规则；同分时按原选项次序破平局。测试中12题含非目标选项的归一化同名干扰项；保留原选项与顺序，目标关系仍唯一，不合并或删除这些题。

K敏感性仅新增K3和K15两次训练，各保持正文FB优化器、损失和32步训练、120步调度；K9模型及重排复用。两个新候选库在相同训练问题上构造，候选来自同一合法池，采用嵌套抽样；测试始终保持原十选项。K3减K9的纠错/退化为199/156，K15减K9为148/130，净差分别为43与18。单个种子无法刻画训练随机性，三个K点也不用于重新选择主结果模型。

过程记录的K3、K15训练耗时分别约为9,944秒和14,280.6秒。前者不包含首次保存中断造成的额外开销；K9含恢复过程的总训练成本未重测。因此，这些记录仅说明本轮完整执行的训练阶段耗时，不构成三组完整成本比较。更大的K会改变候选计算量，固定优化步数不等同于等FLOPs预算。
