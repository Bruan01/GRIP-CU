# 给 Gemini 的论文写作交接包

整理日期：2026-11-09（Asia/Shanghai）。这是一次可复核的静态交接，不是新论文版本。

## 使用方法

1. 将 `01_CONTEXT.md` 和 `02_EVIDENCE.md` 交给 Gemini；复制 `03_PROMPT.md` 作为首条提示。
2. 需要逐段改写时，同时提供当前 `../main/main.pdf`；需要改LaTeX、检查引用或核对来源时，使用本目录 `SC-CL_Gemini_handoff_20261109.zip`。
3. ZIP若无法由所用界面读取，请先在本地解压，再提供其中的Markdown、PDF、TeX和BibTeX文件。本交接不假定Gemini能访问本机路径或自动读ZIP。
4. `02_EVIDENCE.md`已列出正文尚未整合的新NELL结果。以完整证据确定主张，不把旧稿的“未完成”视为当前事实。

## 阅读顺序

- `01_CONTEXT.md`：研究背景、方法、叙事、写作要求、术语与禁区。
- `02_EVIDENCE.md`：可引用数值、来源、模型身份、未完成事项与最新变化。
- `03_PROMPT.md`：可直接粘贴的写作指令与交付格式。
- ZIP中的 `11_paper/main/`：当前正式正文、参考文献、结果表、机制图及14页PDF。
- ZIP中的 `11_paper/artifacts/`：所选结果JSON/CSV和审计。`../`路径只在仓库中适用；压缩包内按仓库相对路径定位。

这是对用户已提供项目背景和本地可见文件的整理，不包含隐藏推理或不可访问的历史聊天。未向Gemini或任何外部服务发送文件。当前PDF为11月8日版本，新NELL结果只是交接补充，尚未更新该PDF。

`manifest.json`记录快照来源、SHA256及验证范围。打包不包含模型权重、优化器状态、原始全候选评分大文件或私密配置；这些仍在实验归档中。原实验文件没有因交接被修改。
