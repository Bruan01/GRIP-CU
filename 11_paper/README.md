# 11 Paper

推荐结构：

1. Abstract
2. Introduction
3. Related Work
4. Problem Formulation
5. Method
6. Experiments
7. Analysis / Discussion
8. Conclusion

## Introduction 必须形成逻辑链
Background
→ Problem
→ Limitation
→ Key Idea
→ Method
→ Results
→ Contributions

## Contribution 不等于模块数量
好的 contribution 可以是：
- 一个新问题
- 一个新算法
- 一个新评价协议
- 一个重要实证结论
