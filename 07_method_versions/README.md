# 07 Method Versions

## 目标
管理算法迭代，而不是只保存最终方法。

建议结构：
- v0_baseline_plus_simple_change/
- v1_first_core_idea/
- v2_improved/
- v3_final/

每个版本必须记录：
- Motivation
- 与上个版本差异
- Algorithm
- Loss
- Hyperparameters
- Expected Benefit
- Known Risk
- 对应实验编号

## 科研循环
Method v1
→ Experiment v1
→ Failure Analysis
→ Method v2
