# 06 Hypothesis

## 目标
把方法想法转成可验证、可证伪的科研假设。

## 模板
Observation:
现有方法出现 ______。

Hypothesis:
我们认为原因是 ______。

Prediction:
如果加入 / 修改 ______，
那么指标 ______ 应该改善，
而指标 ______ 不应明显下降。

## 示例
如果图更新只训练新增事实，会造成旧结构知识遗忘；
如果使用结构感知 replay，则旧知识 retention 应提升，同时新知识学习能力保持。
