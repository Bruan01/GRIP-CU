# 01 Problem / Research Question

## 目标
明确科研问题，而不是先想模块。

## 必答问题
- 我们研究的对象是什么？
- 当前方法在哪个场景下表现不好？
- 为什么这个问题值得解决？
- 这个问题是算法问题、系统问题、分析问题还是 benchmark 问题？
- 最终希望改善什么指标？

## 建议产出
- problem_statement.md
- research_questions.md
- motivation.md

## AI 可辅助
- 把模糊想法压缩成 Research Question
- 从已有论文局限中提炼问题
- 帮助区分“工程需求”和“科研问题”
