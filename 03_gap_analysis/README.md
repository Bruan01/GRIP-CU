# 03 Research Gap Analysis

## 目标
从 Related Work 中找到真正可发表的空白。

## Gap 模板
Existing methods can ______,
but they still fail to ______,
because ______.
Therefore, we investigate ______.

## 必答问题
- 最近最接近的 3–5 篇论文是谁？
- 它们分别解决了什么？
- 我的 idea 是否只是模块替换？
- 如果 reviewer 问“为什么不用已有方法 X”，怎么回答？
- 我们的创新到底是任务、算法、训练机制、评价协议，还是系统目标？
