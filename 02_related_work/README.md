# 02 Related Work

## 目标
理解当前领域已经做到哪里。

## 每篇论文至少记录
- Paper
- Venue / Year
- Research Problem
- Core Method
- Dataset
- Metrics
- Main Results
- Strengths
- Limitations
- 与本项目关系

## 不要只做
“论文 A 做了什么、论文 B 做了什么”的摘要。

## 真正要做
横向比较：
- 相同问题用了哪些不同方法？
- 哪些设计已经非常拥挤？
- 哪些 benchmark 被广泛使用？
- 哪些 limitation 被多篇论文重复提到？

## 推荐文件
- literature_matrix.csv
- paper_notes/
- related_work_summary.md
