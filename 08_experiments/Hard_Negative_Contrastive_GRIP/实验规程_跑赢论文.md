# 实验规程：在论文口径下超过 GRIP（2026-10-25 定稿，训练开始前提交）

本文件在任何 v2 训练开始**之前**提交，目的是事先固定选择规则，避免事后挑结果。之后任何修改都必须另起一次提交，并写明原因。

## 1. 评测口径（与论文一致，不可更改）

- 自由生成，贪心解码，`max_new_tokens=1000`（与官方代码一致）。
- 用官方 `extract_tag_content(text, "answer")` 抽取 `<answer>`，之后用 `normalize_answer` 做精确匹配（`official_em`）。
- 题面、system prompt、10 选 1 列表都与官方 `process.py` 相同。**不使用闭集解码**。
- NELL23K test 有两个口径：
  - **主口径 4,943 题**（`official_harness_em`）：官方 `process.py` 用 `split("\n")[:-1]` 读文件，会丢掉末行（`nell23k:test:4943`）。
  - 同时报告全部 4,944 题的结果（`official_em`）。
- 论文的 25,445 / 4,961 / 4,952 条、200 种关系，是官方 `preprocess.ipynb` 过滤非 concept 三元组**之前**的统计；过滤后是 24,321 / 4,951 / 4,944 条、198 种关系，与我们使用的数据相同。

## 2. 依据优先级

1. 论文正文与 Table 13 写明的设置：一律照论文。
2. 论文没有规定的设置：跟随官方代码（commit d423742）。
3. 官方代码与论文冲突时（如 NELL 的 r=8、ε=1e-8、全序列损失）：照论文。

## 3. 选择规则

- 所有超参数和方法变体**只看 validation**（4,951 题，主口径 4,950 题）来挑选。
- test 只在配置定稿后**每个最终配置跑一次**，不再据此调整任何东西。
- 每个试过的变体（包括失败的）都要记录在 `results/runs/paper_v2_*/VARIANTS.md` 里：配置、validation 结果、是否入选。
- 方法改进只在 S2 损失上做。候选：V1 InfoNCE 用总 log-prob 打分；V2 λ=0.5；V3 V1/V2 组合或控制训练轮数。B1 不做任何调整。

## 4. 种子与判定标准

- 预先定好 3 个种子：**2026、2027、2028**。B1 和最终方法各跑 3 个种子（共享同一个 S1，S1 用种子 2026）。
- 报告各种子 test 结果的均值 ± 标准差，并对每个种子做配对 McNemar 精确检验（方法 vs 同种子 B1）。
- **"跑赢论文"必须同时满足：**
  1. 3 个种子在主口径下的 test 均值 > **87.74%**（论文 GRIP-Qwen-7B，NELL23K）；
  2. 显著优于同条件 B1：3 个种子都比 B1 高，并且把 3 个种子的配对结果合并后，McNemar 检验 p < 0.05。
- 只满足其中一条，就如实写成"超过论文数字但未显著优于复现 B1"或"显著优于 B1 但未超过论文数字"。
- FB15K-237（论文 88.75%）在 NELL 定稿后用同一规程执行。

## 5. v1 结果的地位

`results/runs/paper_nell23k/`（S2 新建 AdamW、权重衰减 0、只解码 test）是 v1，只作为探索性结果：B1 86.37%，Calibrated 86.55%，Soft-Mix 87.32%（单种子、4,944 题）。v1 的 test 结果已经看过，所以 v2 的配置选择不能依据它们。

## 6. 2026-10-25 修订：验证集自动搜索（搜索开始前登记）

根据新增自动超参数搜索的要求，增加 `configs/run_validation_hpo.sh`，详细流程见 `VALIDATION_HPO.md`。这是原选择规则的明确补充，并非原始预注册内容；当前训练队列保持不变，尚未启动任何搜索试验。

- 默认总预算 8 次、搜索种子 2026，共享 S1 和同一份 train-only 冻结负样本。
- 搜索 Soft-Mix / Calibrated、对比损失缩放系数 0.1–1.0（对数空间）、S2 训练轮数 1/3/5/10；学习率、温度、负样本、mean-logprob 打分、论文评测口径固定。
- 前四次是两种方法各自缩放 1.0/0.5、10 轮，剩余由 Optuna TPE 根据 validation 提议。不启用剪枝，不使用 test，也不据 test 扩展搜索范围。
- 各试验关闭训练损失阈值早停，按指定轮数训练结束后才评测 validation。这是轮数搜索的显式变体，不是训练中逐 checkpoint 选优；B1 保持原早停规程。
- 以完整验证集解码、4,950 题 `official_harness_em` 选优，平分取较早试验。所有参数、失败与结果保存在 `<ROOT>/hpo_seed2026/{trials.json,VARIANTS.md}`；这两个文件是自动搜索部分的变体台账。
- 整个预算完成后固定最佳配置，再执行第 4 节的最终三种子复现与 test 判定。有限预算的最佳值不等于全局最优，也不直接证明超过论文。
